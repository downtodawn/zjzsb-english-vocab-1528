## 🚀 快速开始

### 1. 安装 Anki

| 设备 | 装什么 | 从哪装 |
|---|---|---|
| **鸿蒙手机** | Anki记忆卡 | 鸿蒙应用市场搜「Anki记忆卡」|
| **安卓手机** | AnkiDroid | [官方 GitHub Releases](https://github.com/ankidroid/Anki-Android/releases)（开源免费）|
| **Windows** | Anki | [apps.ankiweb.net](https://apps.ankiweb.net/) |
| **iPhone** | AnkiMobile | App Store（付费 ¥198）|

### 2. 导入词书

```
① 下载 apkg 文件到手机
② 用文件管理器点击它
③ 弹出「打开方式」时选 Anki
④ 等 1-2 分钟（71 MB，含 3058 个音频）
```

### 3. 设置（重要）

```
长按词库 → Deck options / 词库设置

  每日新卡上限：30
  每日复习上限：400
  目标记忆率（FSRS）：90%
```

### 4. 开始背

```
看卡片 → 点「显示答案」→ 点 4 个评分按钮之一

收藏：点星号 / 标记
```

## 🔍 常用搜索语法

在 Anki 的「浏览 / 卡片浏览器」搜索框里输入：

| 想干什么 | 搜索条件 |
|---|---|
| 只背 L1 核心 | `tag:L1核心` |
| 只背科技话题 | `tag:L2话题-科技` |
| 2026 新词 | `tag:热点` |
| 我的收藏（生词本）| `tag:marked` |
| 有易混提示的词 | `tag:易混` |
| 真题熟词僻义 | `tag:真题熟词僻义` |
| 还没学过的 | `is:new` |
| 今天到期的 | `is:due` |

**规则：空格 = AND（同时满足），减号 = 排除。**

```
tag:L1核心 is:new           L1 里还没学的
tag:L1核心 tag:marked       L1 里我收藏的
tag:L1核心 -tag:marked      L1 里除收藏外的
tag:L1核心 tag:词组         L1 里的词组
```

## ✨ 这本词书的特点

### 例句全部来自真题语境

不是「This is a good example」这种模板句 —— 每个例句都出自真实的考题原文。

```
2012 → 24-hour work shifts（shift = 轮班）
2015 → board a commuter train（board = 登机/上车）
2017 → devoted to one cause（cause = 事业）
2025 → Many carriers offer plans（carrier = 运营商）
```

**74 条熟词僻义，42 条能查到真题原句和年份。**

### 例句直译，不加修饰

```
原文：The discovery suggests these whales are not just passing through.
译文：这一发现表明这些鲸鱼不只是路过。
```

**不做「意译美化」，方便对照记忆。**

### 标签系统开箱即用

1275 种标签已经全部打好，导入就能搜：

```
层级：L1核心 / L2话题-XX / L3扫盲
类型：单词 / 词组 / 复合词 / 专名
话题：科技 / 生态 / 医疗 / 经济 / 教育 / 心理 / 社会 / 文化 / 逻辑 / 通用
特殊：热点 / 易混 / 介词短语 / 真题熟词僻义 / 常见僻义
词族：词族-take / 词族-make / 词族-expect …
```
